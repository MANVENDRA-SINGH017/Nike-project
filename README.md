# Nike Social Media Analytics

An end-to-end data analytics project focused on understanding short-form social media performance and developing data-driven marketing strategies for Nike.

The project analyzes 48,000+ YouTube Shorts and TikTok videos to identify patterns across content, creators, markets, publishing times, trends, and audience engagement.

## Tools & Technologies

- Python — Pandas, Seaborn, Scikit-learn
- MySQL — Data analysis and business queries
- Power BI — Interactive dashboard and visualization
- Machine Learning — Viral content classification
- GitHub — Project documentation and portfolio

## Project Objectives

- Identify high-performing content categories and formats
- Analyze platform, country, and market performance
- Identify high-performing creators
- Determine effective publishing times
- Analyze trends, sounds, and seasonal patterns
- Build a model to identify content with high viral potential
- Translate analytical findings into strategic recommendations for Nike
